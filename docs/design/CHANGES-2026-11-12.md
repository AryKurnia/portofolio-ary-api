## A. Butuh API

### 1. Sertifikat (fitur baru)
Usulan lengkap: **`docs/design/PROPOSAL-certificates-api.md`** (skema, endpoint, validasi, contoh, pertanyaan terbuka). Ringkasnya:
- Resource `Certificate { id, name, issuer, issued_at "YYYY-MM", expires_at|null, credential_id|null, credential_url|null, file|null, is_published, sort_order }`.
- Publik: `GET /certificates` + field `certificates` di `GET /portfolio` (hanya yang terbit, urut `sort_order`).
- Admin: `GET/POST /admin/certificates`, `PATCH/DELETE /admin/certificates/{id}`, `PATCH /admin/certificates/reorder` (`ReorderInput`).
- Upload: `kind=certificate_file` di `POST /admin/uploads` — PDF/PNG/JPEG/WebP, **maks 5 MB** (kind lain tetap 2 MB); PDF disajikan `Content-Disposition: inline`; 409 di `DELETE /admin/uploads/{id}` bila masih dipakai.
- Validasi 400 (pesan sudah dipakai di desain): `expires_at` < `issued_at` → "Expiry must be after the issue date."; terbit tanpa `file_id` dan tanpa `credential_url` → "Add a file or a credential URL to publish."

### 2. Project open source (perluasan `projects`)
- Field baru di project: **`repo_url`** (opsional; URL repo GitHub publik). Kosong = bukan open source.
- Objek baca-saja **`repo`** hasil sinkronisasi GitHub API: `{ language, stars, license, archived, synced_at }` (nullable bila belum/gagal sinkron). Sinkron saat simpan + cache 6–12 jam; gunakan token server agar tidak kena rate limit; jangan dipanggil dari browser.
- Validasi saat simpan: repo tidak ada / privat → 400 `details: [{ field: "repo_url", message: "Repository not found or private." }]`.
- Filter: `GET /projects?type=open-source` (dan `meta.total` per filter) untuk Projects Archive.
- Ditampilkan di kartu sebagai chip "Open source", "TypeScript · ★ 12 · MIT", dan tombol Source.

## B. Tidak butuh perubahan API (info saja)
- **Field upload terisi** (pratinjau + Replace/Remove) — memakai respons upload yang sudah ada (`width`, `height`, `mime`, `variants`).
- **Pemilih bulan–tahun** baru — nilai tetap `YYYY-MM`; aturan validasi sama (End ≥ Start; tanggal mulai tidak di masa depan).
- **Ikon situs** (favicon "^|<") — aset statis frontend.
